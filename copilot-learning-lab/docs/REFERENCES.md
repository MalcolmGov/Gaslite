## What each reference informed

**Agent Builder (build agents, share and manage)**
- The new agent screen shows the heading "What can I take off your hands today?", a composer with **+** and microphone, and **Skip to configure** (screenshot).
- The Configure layout has cards for name and description, Instructions, Knowledge (with toggles for *Search all websites*, *Only use specified sources* and *Reference org chart and profile info*), Capabilities, and Suggested prompts shown as Title/Message rows (screenshot).
- Field limits: name up to 30 characters, description up to 1,000, instructions up to 8,000, and up to 20 knowledge sources.
- There are **Describe**, **Configure** and **Try it** views. Try it is only enabled once the agent has a name, description and instructions.
- **Create** makes the agent private to its owner and only available to you. **Share** opens a dialog with *Add a name, group, or email*, the roles **Can chat** / **Can edit** (a group can only be *Can chat*), and a *Send notification* checkbox. The dialog also has *Org-wide sharing for chat access* (subject to admin policy) and *Copy chat link*.
- Sharing an agent does not grant access to its knowledge sources. The agent respects each user's own permissions.
- **Update** publishes changes made after the agent was created.
- For Actions and integrations, use Copilot Studio.

**Cowork (get started, use Cowork)**
- Cowork is opened with the **Chat | Cowork** toggle at the top.
- The home page has a chat input, suggested prompts (*Catch me up*, *Organize my inbox*, *Prep for a meeting*, *Plan an event*…) and recent tasks.
- The **+** button offers *Add work context*, *Upload images and files* and *Attach cloud files*.
- While Cowork works, it shows a thinking indicator, skill messages ("Preparing to compose emails"), tool steps ("Composing your email"), a streamed response and a connection status.
- Clarifying questions offer a set of choices: arrow keys to move, Space to select, then **Submit**, or **Skip**.
- Approvals show a preview and an action-specific button (**Send**, **Create**). A dropdown offers "don't ask again" options for the session, **Approve All (n)** appears when several approvals are pending, and **Cancel** skips the action. **Show parameters** reveals technical details.
- The side panel has Progress (with a percentage), Input folder, Output folder (Download / Preview / Download All as a .zip), Skills (chips), Schedule and Permissions.
- Pause can finish the current step first (soft) or stop immediately (hard). Resume and Cancel are also available.
- Task filters: *Needs your input*, *In progress*, *Complete*, *Automations* and *Unread*.
