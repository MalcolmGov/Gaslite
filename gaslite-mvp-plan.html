MVP Scope
Three interconnected portals delivering the core gas delivery experience

Customer Portal

Customer
  • Browse product catalogue (9kg, 19kg, 48kg)
  • Place orders with delivery address
  • Real-time order status tracking
  • Order history and reordering
  • Secure card payment at checkout
  • Profile management
  • Delivery location via GPS/map

Driver Portal

Driver
  • Driver application with document upload
  • Available orders within 10km radius
  • Accept/decline order assignments
  • Order status updates (en route, delivered)
  • Delivery history and earnings view
  • Availability toggle (online/offline)

Admin Dashboard

Admin
  • Overview metrics and KPI dashboard
  • Manage products, pricing, and inventory
  • Review and approve driver applications
  • Monitor all active and past orders
  • Customer and driver management
  • Revenue and order analytics

MVP Focus: The MVP delivers the complete order-to-payment-to-delivery loop. A customer browses products, pays securely via card, a nearby driver accepts and delivers the order, and the admin oversees the entire operation. Push notifications and SMS alerts are deferred to Phase 2.

Technology Stack
Modern, scalable, and cost-effective technology choices

Frontend

  • React 18 with TypeScript
  • Tailwind CSS + shadcn/ui components
  • Framer Motion for animations
  • TanStack Query for data fetching
  • Vite for fast builds
  • PWA with service workers

Backend

  • Node.js with Express
  • PostgreSQL database
  • Drizzle ORM for type-safe queries
  • Passport.js authentication
  • Cloud Storage for file uploads
  • REST API architecture

Infrastructure

  • Cloud Hosting with auto-scaling
  • SSL/HTTPS encryption
  • CDN for static assets
  • Automated backups for database
  • CI/CD deployment pipeline
  • Monitoring and error tracking

Why this stack? React + Node.js enables rapid development with a single language (TypeScript) across the entire application. PostgreSQL provides enterprise-grade reliability. The PWA approach means customers and drivers get a native app-like experience without App Store fees or approval delays. Total monthly hosting costs estimated at under R500/month at launch.
